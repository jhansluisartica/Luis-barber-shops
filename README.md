## 🚀 Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo:
   `luis-barber-shop`
2. Sube **todo el contenido de esta carpeta** al repositorio.
3. Verifica que `index.html` quede en la raíz del repositorio.
4. En GitHub entra a:
   **Settings → Pages**
5. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
6. Guarda los cambios.
7. GitHub generará la dirección pública de la página.

### Importante

No cambies los nombres de las carpetas `css`, `js` e `img`, porque las páginas utilizan rutas relativas.

El proyecto está preparado para funcionar como sitio estático. No necesita PHP ni un servidor backend para mostrar las páginas.

La reserva utiliza `localStorage` del navegador para guardar temporalmente los datos de la reserva en el dispositivo del visitante.
